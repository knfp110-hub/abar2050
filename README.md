# ABAR 2050 Android-first starter

This is a small progressive web app (PWA) starter, not an APK and not a complete autonomous AI platform. It includes a prompt builder, caption/hashtag starter, local image sharing handoff, and checklist. It does not generate images, call AI APIs, schedule posts, store cloud data, or publish to TikTok automatically.

## Install on Android
1. Host this folder on an HTTPS static host (for example, GitHub Pages).
2. Open the hosted URL in Chrome on Android.
3. Open Chrome menu and choose **Install app** or **Add to Home screen**.

An HTTPS host is required for service worker/offline support. For a native APK, open a wrapped Android project in Android Studio and build it with the Android SDK; those build tools are not included here.
